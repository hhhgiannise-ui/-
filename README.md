# AA 旅行账本（TripAA）

> 代号：tripshare · 小圈子共享的旅行费用分摊微信小程序

**一句话**：建一次旅行，拉家人朋友进团，谁花钱随手记一笔，结束后自动算清谁该给谁多少钱——再也不用在群里对账。
