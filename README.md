# 错题追问教练（Mistake Coach）

> 代号：mistake-coach · 不告诉你答案的考研错题教练

**一句话**：拍照录入错题，AI 先做结构化分析（错因/知识点/难度），再（V2 起）用苏格拉底式追问逼你自己想通——而不是直接给答案。
